# Samples from an `acif` object

Samples from an `acif` object

## Usage

``` r
ralife_cif(n, x)
```

## Arguments

- n:

  number of samples

- x:

  the output of a
  [`calc_cif()`](http://lcgodoy.me/abslife/reference/calc_cif.md) call
  (an `acif` object).

## Value

a `data.frame` with the sampled `event_type` and `lifetime`.
