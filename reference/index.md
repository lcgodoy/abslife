# Package index

## All functions

- [`aart`](http://lcgodoy.me/abslife/reference/aart.md) : Consumer

- [`aloans`](http://lcgodoy.me/abslife/reference/aloans.md) : Consumer
  automobile loans dataset

- [`aloans_recov`](http://lcgodoy.me/abslife/reference/aloans_recov.md)

  Calculates a full loan amortization schedule

  Calculates the cumulative distribution function (CDF) from estimated

- [`calc_osup()`](http://lcgodoy.me/abslife/reference/calc_osup.md) :

- [`calculate_apv()`](http://lcgodoy.me/abslife/reference/calculate_apv.md)
  : Calculates the actuarial present value (APV) of a loan

- [`disc_fac()`](http://lcgodoy.me/abslife/reference/disc_fac.md) :
  Calculate discount factors for an effective interest rate

- [`estimate_hazard()`](http://lcgodoy.me/abslife/reference/estimate_hazard.md)
  : Estimating the discrete time, hazard rate subject to left-truncation

- [`ev_life()`](http://lcgodoy.me/abslife/reference/ev.md) : Calculates
  expected value from an estimated lifetime distribution

- [`extend_hazard()`](http://lcgodoy.me/abslife/reference/extend_hazard.md)
  : Extrapolate hazard rates beyond observable region

  Plots an `alife` (or `alife_multi`) object with `ggplot2`

- [`mbalt`](http://lcgodoy.me/abslife/reference/mbalt.md) : Consumer
  automobile leases from Mercedes-Benz Auto Lease Trust 2017-A
