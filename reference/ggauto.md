# Plot an `alife` (or `alife_multi`) Object using `ggplot2`

Plot an `alife` (or `alife_multi`) Object using `ggplot2`

## Usage

``` r
ggauto(object, ...)
```

## Arguments

- object:

  An object of class `alife` or `alife_multi`.

- ...:

  Arguments passed to methods (e.g., `ci_level`).

## Value

A `ggplot` object.
